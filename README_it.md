# YOLO Completion Only

Questo fork mantiene soltanto il completamento automatico del testo. Non include la chat, gli agenti o l'indicizzazione del vault di YOLO.

La documentazione aggiornata per installazione, configurazione e integrazione è disponibile in [inglese](README.md) e [cinese semplificato](README_zh-CN.md). L'identificatore del plugin resta `yolo`, quindi sostituisce YOLO nello stesso vault.

Basato su [YOLO](https://github.com/Lapis0x0/obsidian-yolo), con licenza [MIT](LICENSE).
