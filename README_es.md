# YOLO Completion Only

Esta bifurcación conserva únicamente el autocompletado de texto. No incluye el chat, los agentes ni la indexación de la bóveda de YOLO.

La documentación actual de instalación, configuración e integración está disponible en [inglés](README.md) y [chino simplificado](README_zh-CN.md). El identificador del plugin sigue siendo `yolo`, por lo que sustituye a YOLO en la misma bóveda.

Basado en [YOLO](https://github.com/Lapis0x0/obsidian-yolo), bajo la licencia [MIT](LICENSE).
